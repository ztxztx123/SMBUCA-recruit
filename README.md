# 协会招新报名表处理工具

使用 Python 和 pandas 处理问卷导出的 CSV 报名表，
提供数据概览、报名信息校验、问题清单和志愿统计。
程序不会修改输入文件。

## 功能

1. 读入与概览
   - 检查是否包含所需字段。
   - 打印数据总行数和每列空值数量。
   - 检查完全重复的行。

2. 校验与清洗
   - 校验学号是否为纯数字。
   - 校验邮箱是否等于“学号@smbu.edu.cn”。
   - 找出同一学号的重复报名。
   - 导出问题记录及其全部问题原因。

3. 统计与导出（尚未实现）
   - 按第一志愿统计人数。
   - 统计填写两个、一个和零个志愿的人数。
   - 导出干净数据。

## 运行环境

- Python：3.14
- 使用 venv 隔离项目环境，使用 pip 安装依赖。
- 依赖及版本见 requirements.txt。

## 安装与运行

```bash
# 创建虚拟环境
python -m venv .venv

# 激活虚拟环境（Linux / macOS）
source .venv/bin/activate

# 激活虚拟环境（Windows）
.\.venv\Scripts\Activate.ps1

# 安装项目依赖
python -m pip install -r requirements.txt

# 运行程序
python main.py test.csv

# 查看帮助
python main.py --help
```

## 输入格式

CSV 必须包含以下字段：

姓名、学号、邮箱、志愿1、志愿2、推荐人

示例：

```csv
姓名,学号,邮箱,志愿1,志愿2,推荐人
张三,001234,001234@smbu.edu.cn,开发,学术,
李四,20260002,20260002@smbu.edu.cn,运营,,王老师
```

文件使用 UTF-8 编码，允许带 BOM。
缺少必需字段时，程序提示错误并停止处理。

## 输出

输出文件保存在运行命令时所在的目录：

| 文件 | 内容 |
|---|---|
| problems.csv | 问题记录、数据记录序号和问题原因 |
| summary.csv | 第一志愿人数汇总 |
| clean.csv | 通过校验的干净数据 |

输出使用 UTF-8 BOM 编码，不包含 pandas 行索引。
再次运行会覆盖同名输出文件。

## 规则与假设

- 学号作为字符串读取，保留前导零。
- 学号必须非空，且仅包含普通数字 0–9；暂不限制位数。
- 完全重复行按输入字段的原始值判断。
- 校验和统计前，去除字段首尾的空白字符。
- 空字符串和只有空白字符的字段均视为空值。
- 邮箱去除首尾空白后，必须严格等于“学号@smbu.edu.cn”。
- 同一非空学号出现两次或以上，所有相关记录均进入问题清单，
  不自动选择保留哪一条。
- 一行存在多个问题时，记录全部原因。
- 姓名、志愿和推荐人为空暂不判为错误。
- 不限制志愿的具体名称，也不要求两个志愿不同。
- 志愿统计以清洗后的数据为准，第一志愿为空的记录也纳入分组。
- 数据记录序号从 1 开始，不包含表头，不等同于文件物理行号。
- 输入中的空白行保留并计入数据行数。
